# Temporal validation of NHANES depression-symptom prioritisation models

This repository is the reproducibility package for a temporal validation and
model-maintenance study of depression-symptom prioritisation models using public
NHANES data. It contains the analysis code, frozen de-identified analytic
panels, derived outputs needed to inspect the reported results, and code to
generate every research figure.

It intentionally does **not** contain manuscript-building code, manuscript or
submission files, author metadata, editorial correspondence, backups, raw XPT
downloads, or operating-system artefacts.

## Release contents

- `code/` — model fitting, survey-jackknife inference, measurement analysis,
  deterministic tests, and figure-generation scripts.
- `data/frozen/` — the two analysis-ready, de-identified panels used by the
  released analyses.
- `outputs/` — frozen aggregate analysis outputs used for tables, figures, and
  result checks. The `review/` subdirectory contains the development-selected
  regularised-model and benchmark analyses that support the final primary
  claims.
- `figures/` — target directory for files regenerated by the figure scripts;
  generated binaries are deliberately not versioned.

Raw NHANES public-use data are distributed by NCHS, not duplicated here. See
[`data/README.md`](data/README.md) for provenance and use notes.

## Environment

The package was verified with Python 3.10 and the package versions in
`requirements.txt`.

```bash
python -m venv .venv
# macOS/Linux
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Reproduce the released analyses

Run commands from the repository root. The frozen panels and existing derived
outputs are included; rerunning model fitting will overwrite the corresponding
files in `outputs/review/`.

```bash
# Fast deterministic implementation checks
python code/test_review_methods.py

# Development-selected regularised model, temporal maintenance, and reduced-set analyses
python code/review_reanalysis.py

# Primary-model capacity and poverty-ratio benchmark sensitivities
python code/regularised_primary_sensitivity.py

# Tie-order and population-capacity sensitivity analyses
python code/final_submission_analysis.py

# Generate all main/supplementary research figures
python code/make_publication_figures.py
python code/make_primary_regularised_figure.py
python code/make_regularised_capacity_figure.py
```

The full model-fitting sequence can take substantial time on a typical laptop.
The frozen outputs are included so that readers can inspect reported values and
generate figures without rerunning every computationally intensive step.

The ordinal PHQ-9 measurement analysis is available separately because it is
computationally intensive:

```bash
python code/w8_measurement_invariance.py --out outputs/w8/recomputed
```

Its released, corrected outputs are retained in `outputs/w8/corrected/`.

## Scope and interpretation

This package supports reproduction of the reported analyses from the frozen
analytic panels. It does not claim to be an independent re-extraction from raw
NHANES files, a rerun of every historical development experiment, or a clinical
decision-support system. Results should be interpreted together with the
limitations described in the associated manuscript, including uncertainty from
model development and complete-case selection.
